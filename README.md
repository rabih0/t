# Familienplaner

Eine einfache Webanwendung zur Verwaltung von Familienterminen.

## Funktionen

- Termine hinzufügen, bearbeiten und löschen
- Termine als erledigt markieren
- Termine nach Kategorien filtern
- Termine nach Mitgliedern filtern
- Termine nach bevorstehenden, arbeitsbezogenen und erledigten Terminen auflisten
- Responsive Design
- PWA (Progressive Web App) fähig
